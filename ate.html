IN DEVELOPMENT2026

Modular Semiconductor Test Station

ATE (Automated Test Equipment) คือระบบที่ใช้คอมพิวเตอร์และอุปกรณ์อิเล็กทรอนิกส์เพื่อส่งสัญญาณ วัดค่าตอบสนอง และประเมินผลการทดสอบของอุปกรณ์โดยอัตโนมัติ แนวคิดนี้ถูกใช้อย่างแพร่หลายในการทดสอบชิ้นส่วนอิเล็กทรอนิกส์และ semiconductor

สำหรับโปรเจกต์นี้ แนวคิดหลักคือการทำ test station แบบ modular ที่สามารถเปลี่ยน socket หรือ test module ได้ตามอุปกรณ์ที่ต้องการทดสอบ ทำให้สถานีเดียวสามารถนำไปทดลองกับงานหลายรูปแบบ และสามารถต่อยอดระบบวัดในอนาคตได้

01 / IDEA

แนวคิด

ลดความยุ่งยากของการต่ออุปกรณ์วัดหลายชิ้นเข้าด้วยกัน โดยรวมการเชื่อมต่อและขั้นตอนการทดสอบไว้ในสถานีเดียว และออกแบบให้ส่วนที่สัมผัสกับอุปกรณ์เปลี่ยนได้

02 / BASIC FLOW

ทำงานอย่างไร?

ใส่อุปกรณ์ที่ต้องการทดสอบ → เชื่อมต่อผ่าน test socket / interface → ส่งสัญญาณหรือจ่ายไฟ → วัดค่าที่ตอบกลับ → บันทึกผล → ตรวจสอบว่าอยู่ในช่วงที่กำหนดหรือไม่

03 / WHY MODULAR

ทำไมต้อง Modular?

เพราะอุปกรณ์แต่ละชนิดอาจมีรูปแบบขา การเชื่อมต่อ และเงื่อนไขการทดสอบต่างกัน การแยก test module ทำให้เปลี่ยนส่วนที่ต้องการได้โดยไม่ต้องสร้างทั้งสถานีใหม่

04 / NEXT

ต่อยอด

สามารถต่อยอดไปสู่การควบคุมการทดสอบด้วยซอฟต์แวร์ การเก็บข้อมูลอัตโนมัติ การสร้าง test sequence และการแสดงผล pass / fail เพื่อให้การทดลองเป็นระบบมากขึ้น
