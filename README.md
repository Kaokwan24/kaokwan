# KAOKWAN PAKEEWUT — Personal Resume Website

เว็บไซต์ Resume ส่วนตัวของ **KAOKWAN PAKEEWUT** นักศึกษาชั้นปีที่ 4 สาขาวิศวกรรมไฟฟ้าสื่อสาร มหาวิทยาลัยศิลปากร

เว็บไซต์นี้จัดทำขึ้นเพื่อรวบรวมข้อมูลส่วนตัว ประสบการณ์การเรียนรู้ และผลงานโปรเจกต์ในรูปแบบเว็บไซต์หลายหน้า

## Pages

- **HOME** — แนะนำตัวและภาพรวมเว็บไซต์
- **ABOUT** — ข้อมูลส่วนตัว ความสนใจ และทักษะ
- **EXPERIENCE** — ประสบการณ์การเรียนและการอบรม
- **PROJECTS** — ผลงานและโปรเจกต์ที่เกี่ยวข้องกับการเรียน
- **CONTACT** — ช่องทางการติดต่อ
